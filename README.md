# Accelerate BASSO Portal

A curated discovery portal for resources produced by the Accelerate BASSO Network — ontologies, publications, tools, datasets, and communities for the behavioral and social sciences.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the portal.

## Adding Resources

Resources are stored as YAML files in `data/resources/`. To add a new resource, either:

- Create a YAML file following the schema in existing files
- [Open an issue](../../issues/new/choose) using the "Add a new resource" template

## Built With

- [Next.js](https://nextjs.org) + TypeScript + Tailwind CSS
- Resource metadata stored as YAML in Git
